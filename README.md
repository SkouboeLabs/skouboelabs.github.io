# SkouboeLabs website

Static website ready for GitHub Pages.

## Publish
1. Create a GitHub account.
2. Create a public repository named `YOUR-USERNAME.github.io`.
3. Upload all files and the `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
6. Use `https://YOUR-USERNAME.github.io/privacy.html` in Google Play Console.

Before final release, add a Privacy Policy link or text inside the game itself. Update the policy and Play Console declarations before adding analytics, ads, accounts, cloud save or other data-handling SDKs.
